# Jurina's Homepage

Just a small corner of the internet where I share a little about myself, my interests, and the music I enjoy.

Thanks for stopping by :D

## Development

Scripts are written in TypeScript under `src/` and compiled to `js/`, which the pages load directly. Commit the compiled `js/` files too, since GitHub Pages serves the repo as-is.

```bash
npm install
npm run build   # or: npm run watch
```
